Adopt a file

Brings a Markdown file that is already in the repository under Subutai, where it sits. Subutai gives it an ID and writes two lines into its front matter, id: and revision:, changes nothing else, and commits that change. The file keeps its ID if you move or rename it later.

It must be committed, with no uncommitted changes. A decision named like DEC-005-….md keeps its number.

Has it already been approved?

Saying yes records your approval. A specification or development plan is always adopted as a draft, then submitted and reviewed.
