### The hook

- **It only runs in a cloud session.** On a developer's own machine
  (`CLAUDE_CODE_REMOTE` unset) it exits at once. It also exits quietly when no
  PostgreSQL binaries are installed, so the integration tests skip as before.
- **It is idempotent.** It initialises `/var/tmp/pgdata` once, as the
  `postgres` user with trust authentication, and starts the server on port
  54329 with its socket in `/var/tmp`. After that it only prints the URL.
- **It is quick.** 2.8 seconds from cold, including `go mod download`; 0.04
  seconds when the database is already running.
- **It runs synchronously**, so the variable is set before the session's
  first command. Async would start sessions a few seconds sooner, but a first
  `go test` could then race the database and skip silently, which is the trap
  this milestone exists to close.
- The URL is `postgres://postgres@localhost:54329/postgres?sslmode=disable`.
  The older handoffs' URL, with password `cromwell`, is for the Docker
  container `cromwell-pg-dev` on Sam's machine, and still works there.

`scripts/test-db.sh` refuses to start if another server already holds the port,
rather than quietly running the tests against it. On a machine running
`cromwell-pg-dev`, keep using that, or set `CROMWELL_TEST_PGPORT`.

### The smoke project

`scripts/smoke-project.sh` rebuilds what `/tmp/cromwell-smoke` was:

- every role on one model, by default `deepseek-chat` through DeepSeek's
  Anthropic-compatible gateway, all set by `SMOKE_*` variables;
- `write-spec` and `write-dev-plan` enabled;
- the design template, which `init` now ships (the script checks);
- a one-sentence design, `docs/greet/time/design.md`, in the template's shape;
- its own database, `cromwell_smoke`, on the test server;
- the UI on `127.0.0.1:8801`, with `ui_actor: sam`.

It refuses to overwrite an existing project or database without
`SMOKE_FORCE=1`, and refuses a database that isn't on `localhost`, because it
drops and recreates its own.

## Traps, new and inherited

- All the traps in the [Stage 1 handoff](handoff-2026-07-30-stage1-complete.md)
  still hold, especially this one: **`go test ./...` without
  `CROMWELL_TEST_DATABASE_URL` skips the integration tests silently.** In a
  cloud session the hook now sets it. Check with `echo $CROMWELL_TEST_DATABASE_URL`
  if a run looks suspiciously fast.
- `/tmp/claude-0` isn't writable by the `postgres` user, which is why the
  cluster lives in `/var/tmp`.
- `init` still says "set ANTHROPIC_API_KEY" whatever the provider. The smoke
  script's closing message names the right variable.
