# Executors — dev plan

**For:** [SPEC-020](../specs/SPEC-020-executors.md), revised after
[REVIEW-020](../reviews/REVIEW-020-executors.md). Stage 3 of
[How M13 and M14 are built](orchestration-M13-M14.md).

## Approach

The foundations go first and alone: the migration, the two state machines,
the store, and the configuration. Everything else builds on their Go API,
which is fixed below so that later tasks can run in parallel without
guessing at each other's names.

Then three waves:
- **Wave 2**, in parallel: the claim service with the dispatcher's races (T2)
  and unmeasured actuals (T3).
- **Wave 3**, in parallel: the safety nets (T4), MCP and the chat skill (T5),
  and the web UI and timeline (T6). Each touches its own files, apart from
  `ui.go`'s route list (T6 only) and `ui_views.go` (T4 only).
- **Wave 4**: the end-to-end and race tests (T7), then the review cycle.

Each implementer works in its own git worktree, runs `go vet ./...`, `gofmt
-l` on the files it touched, and `go test -race -count=1` for the packages it
touched, with `SUBUTAI_TEST_DATABASE_URL` set. The lead merges each task.

## The Go API that T1 fixes

**`internal/lifecycle/claim.go`**

```go
type ClaimState string // "open", "submitted", "returned", "ended"
type ClaimEvent string // "claim", "renew", "submit", "send_back", "resume", "done", "release", "abandon"
func ClaimTransition(from ClaimState, e ClaimEvent) (ClaimState, error) // from "" for "claim"
```

`lifecycle.TaskRelease TaskEvent = "release"` (active → active).

**`internal/store/claims.go`**

```go
type Claim struct {
    ID uuid.UUID; RefType string; RefID uuid.UUID; FeatureID *uuid.UUID
    Kind, Actor, Via string; State lifecycle.ClaimState
    EndReason, EndedBy string
    ClaimedAt, LastActivityAt time.Time; LastActivity, WorktreeSeen string
    DeadlineAt, SubmittedAt, EndedAt *time.Time
}
func CreateClaim(ctx, tx, refType string, refID uuid.UUID, featureID *uuid.UUID, kind, actor, via, worktreeSeen string) (*Claim, error)
func GetClaim(ctx, q, id) (*Claim, error)
func CurrentClaimFor(ctx, q, refType string, refID uuid.UUID) (*Claim, error)   // not ended; ErrNotFound
func LatestClaimFor(ctx, q, refType string, refID uuid.UUID) (*Claim, error)    // any state
func LockCurrentClaimFor(ctx, tx, refType, refID) (*Claim, error)              // FOR UPDATE
func OpenClaimForFeature(ctx, q, featureID uuid.UUID) (*Claim, error)          // state open
func ClaimsToSweep(ctx, q) ([]Claim, error)                                     // open or returned
func TransitionClaim(ctx, tx, c *Claim, e lifecycle.ClaimEvent, actor, activity string, payload map[string]any) error
    // guarded UPDATE … WHERE state = from; sets last_activity(_at) when activity != "";
    // submitted_at / ended_at / end_reason / ended_by as the event implies;
    // audits "claim.<event>" on the claimed item (claim.claimed etc.), payload + claim_id, kind, via
func RecordClaimActivity(ctx, tx, id uuid.UUID, activity, worktreeSeen string) (bool, error) // only WHERE state='open'
func EndClaimsForFeature(ctx, tx, featureID uuid.UUID, actor, reason string) ([]Claim, error)
```

`TransitionClaim`'s end reasons: `done` → `done`, `release` → `released`,
`abandon` → `abandoned`.

**`internal/store/executions.go`**

```go
type Execution struct {
    ID uuid.UUID; RefType string; RefID uuid.UUID; Round int
    Kind, Actor, Model, Via string; DispatchID, ClaimID *uuid.UUID
    Measured, Inferred bool; StartHead string
    StartedAt time.Time; SubmittedAt *time.Time
}
func CurrentTaskRound(ctx, q, taskID uuid.UUID) (int, error) // 1 + count(task.transition request_changes)
func RecordAgentExecution(ctx, tx, taskID, dispatchID uuid.UUID, role, model, startHead string) error // no-op if the dispatch has a row
func RecordClaimExecution(ctx, tx, refType string, refID uuid.UUID, c *Claim, startHead string) (*Execution, error)
func MarkExecutionSubmitted(ctx, tx, by struct{DispatchID, ClaimID *uuid.UUID}) error // latest row of that run or claim
func ExecutionsFor(ctx, q, refType string, refID uuid.UUID) ([]Execution, error)    // ordered by started_at
func TaskUnmeasured(ctx, q, taskID uuid.UUID) (bool, error)
func DeleteExecutionsFor(ctx, tx, refType string, refID uuid.UUID) error
```

**`internal/store/worktrees.go`**: `Worktree.WatchedHead string`;
`SetWatchedHead(ctx, q, worktreeID, head)`; `RecordWorktreeCommit(ctx, tx,
worktreeID, hash, act)`; `IsWorktreeCommit(ctx, q, worktreeID, hash) (bool,
error)`.

**`internal/config`**: `ClaimsConfig{ExpiryHours *int; ChatReviewModel
*string}` at `Config.Claims` (`yaml:"claims"`); `(c *Config) ClaimExpiry()
time.Duration`; `(c *Config) ChatReviewModel(usual string) string` (absent →
the priciest model by output price, ties by name; `same` → `usual`; a name →
it). The loader refuses `expiry_hours` < 1 and an unknown model.

## Risks

- **The dispatcher's start (T2) is the riskiest change**: it touches every
  implement dispatch. T7's race tests and the whole suite guard it.
- **Shared files with M14**: listed in SPEC-020 NFR-3; the handoff repeats
  them for the integrator.
